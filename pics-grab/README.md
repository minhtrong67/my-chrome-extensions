# Pics Grab

Bulk image downloader for Chrome. Scan any page, pick the images you want and save them all at once.
Designed with Microsoft's **Fluent 2** language: system font, Lucide icons, light/dark themes.

**Author:** minhtrong67 · **AI assistance:** Claude (Anthropic) — also credited in *Settings → About*.

## Features

- **Grid or list view** with checkerboard thumbnails, format badges and image sizes
- **Fast selection** — click to select, Shift+click for a range, Ctrl/Cmd+A for all, Esc to clear
- **Filter** by name or by format (JPG, PNG, WebP…)
- **Hide logo images** — detects site logos, brand marks and favicons by file name, page position and shape; a chip reveals them on demand
- **Bulk save with progress** and a Cancel button; per-image save button on every tile
- **JPG conversion** (WebP / PNG / GIF toggles, adjustable quality)
- **Save location** — ask each time, Downloads, or a named subfolder; file name templates with `{original}`, `{date}`, `{time}`, `{datetime}`
- **Right-click any image → Save image with Pics Grab**
- **Settings save automatically**; English and Vietnamese; no remote fonts, icons or scripts

## Install

1. Unzip, then open `chrome://extensions`
2. Turn on **Developer mode** → **Load unpacked** → choose the `pics grab` folder

## Changes in v3.0.0

- Renamed from PixGrab to **Pics Grab**; new Fluent-style logo (`icons/logo.svg` is the source)
- Redesigned popup and settings (navigation pane, autosave, toasts, empty states)
- System font stack; Lucide icons bundled locally (`icons.js`), no icon font
- Settings → About lists the author and Claude as AI assistant
- Includes v2.1.0 *Hide logo images*

# Pics Grab (Tiếng Việt)

Tiện ích Chrome tải hàng loạt ảnh: quét trang, chọn ảnh và lưu tất cả cùng lúc.
Thiết kế theo **Fluent 2** của Microsoft: font hệ thống, icon Lucide, giao diện sáng/tối.

**Tác giả:** minhtrong67 · **AI hỗ trợ:** Claude (Anthropic) — cũng được ghi trong *Cài đặt → Giới thiệu*.

## Tính năng

- **Dạng lưới hoặc danh sách**, thumbnail nền caro, nhãn định dạng và kích thước
- **Chọn nhanh** — bấm để chọn, Shift+bấm chọn dải, Ctrl/Cmd+A chọn tất cả, Esc bỏ chọn
- **Lọc** theo tên hoặc định dạng
- **Ẩn ảnh logo** — nhận diện logo, biểu tượng thương hiệu, favicon; có chip để hiện lại
- **Lưu hàng loạt có thanh tiến trình** và nút Huỷ; mỗi ảnh có nút lưu riêng
- **Chuyển sang JPG** (WebP / PNG / GIF, chỉnh chất lượng)
- **Vị trí lưu** — hỏi mỗi lần, Downloads hoặc thư mục con; mẫu tên tệp `{original}`, `{date}`, `{time}`, `{datetime}`
- **Chuột phải vào ảnh → Save image with Pics Grab**
- **Cài đặt tự động lưu**; tiếng Anh và tiếng Việt; không dùng font, icon hay script từ xa

## Cài đặt

1. Giải nén, mở `chrome://extensions`
2. Bật **Developer mode** → **Load unpacked** → chọn thư mục `pics grab`
