Install in under a minute

Load TagMark as an unpacked extension — no account, no tracking.

Unzip the package

Extract the downloaded zip to a folder you'll keep, such as Documents/bookmark-manager.

Open Extensions

Go to the address below and switch on Developer mode in the top-right corner.

chrome://extensions

Load unpacked

Click “Load unpacked”, select the extracted folder, then pin TagMark to your toolbar.

Quick bookmark shortcut:Alt+Shift+M
