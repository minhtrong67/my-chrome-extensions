Questions, answered

Is YouTube Grid free?
Yes. It is free and open source under the MIT license.
Which browsers does it support?
Chrome, Edge, Brave and other Chromium-based browsers, version 111 or newer.
Does it collect my data?
No. There are no accounts, no analytics and no network requests. Settings stay on your device.
Why install it with Load unpacked?
The download is the extension itself. Chrome can load it directly when Developer mode is on, with no store account needed.
A toggle stopped working after a YouTube update. What now?
YouTube changes its page markup from time to time. Please open an issue on GitHub and it will be looked at.
Is it affiliated with YouTube?
No. YouTube Grid is an independent project. YouTube is a trademark of Google LLC.
