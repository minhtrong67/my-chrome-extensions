# Changelog

## 1.1.0
- Real-browser test suite (21 end-to-end checks) and unit tests.
- Fix: frame agent now restores the browser's own values when switching from a mobile to a desktop device.
- Fix: side buttons of device frames no longer inherit generic button styles.
- Iframe sandbox: frame-busting scripts and `target=_top` links can no longer navigate the host tab.
- Viewport readout with Tailwind breakpoint name; `<meta viewport>` emulation (980px layout without the tag).
- Touch emulation: CSS `hover` / `pointer` media rules, long press (context menu) and Shift + drag pinch.
- Full-page screenshot, one image for all devices in compare mode, grid overlay, QR code for a real phone, pop-out window.
- Favourites, recent devices, saved compare sets, device remembered per site, keyboard navigation in the device list.
- GIF recordings use an adaptive 256-colour palette.
- First-run tour, "Esc closes" option, warning for unsaved form data, sync loop protection.
- Localised store listing (English, Vietnamese), localised device group names.
- Privacy policy and Web Store notes.

- Initial release.
