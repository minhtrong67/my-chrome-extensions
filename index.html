HƯỚNG DẪN CÀI ĐẶT

Cài Đặt Dễ Dàng Chỉ Với 4 Bước

Tất cả tiện ích đều ở dạng mã nguồn mở nguyên bản (Unpacked Extension), không cần cài đặt Node.js hay bất kỳ môi trường lập trình phức tạp nào.

  1. 1

    Tải mã nguồn về máy

    Clone kho lưu trữ GitHub bằng lệnh Git hoặc tải tệp ZIP từ trang dự án rồi giải nén vào ổ đĩa máy tính của bạn.

  2. 2

    Mở trang quản lý Tiện ích

    Truy cập chrome://extensions trên Google Chrome hoặc edge://extensions trên Microsoft Edge từ thanh địa chỉ.

  3. 3

    Bật "Developer mode"

    Gạt công tắc Developer mode (Chế độ dành cho nhà phát triển) ở góc trên cùng bên phải màn hình sang trạng thái Bật.

  4. 4

    Nhấn "Load unpacked" & Chọn thư mục

    Nhấn nút Load unpacked (Tải tiện ích đã giải nén) ở góc trên bên trái, điều hướng đến thư mục tiện ích bạn muốn cài (ví dụ: smartshot, quicknote, bookmark-manager...) và bấm Select Folder.

Tất cả những điều bạn cần biết trước khi cài đặt và sử dụng bộ tiện ích.

Tuyệt đối an toàn. Toàn bộ mã nguồn mở 100% minh bạch trên GitHub. Các tiện ích hoạt động độc lập ngay trên máy của bạn thông qua Canvas API và Web Crypto API, không kết nối internet ra ngoài, không có telemetry và chỉ yêu cầu quyền hạn tối thiểu tuyệt đối cần thiết để thực hiện tính năng.

Rất đơn giản! Bạn chỉ cần mở Terminal trong thư mục dự án và chạy git pull để kéo mã mới nhất về, sau đó vào trang chrome://extensions và nhấn nút biểu tượng Tải lại (Reload icon) của tiện ích.

Bạn chỉ cần truy cập vào chrome://extensions/shortcuts trên thanh địa chỉ, tìm đến tiện ích mong muốn (ví dụ: SmartShot, QuickNote, TagMark) và bấm biểu tượng bút chì để tự do gán bất kỳ tổ hợp phím nào bạn thấy thuận tay nhất.
