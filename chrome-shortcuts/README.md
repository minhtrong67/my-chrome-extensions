# Settings Shortcuts

Open any Chrome settings page instantly with your own keyboard shortcuts.

- **Design:** Microsoft Fluent 2 (logo, colors, components, motion), system font by default
- **Icons:** [Lucide](https://lucide.dev) (ISC), bundled locally in `icons.js`
- **Settings:** language (English / Tiếng Việt), theme (Light / Dark / System), open in new or current tab
- **Shortcuts:** 18 built-in Chrome pages + your own custom URLs and key combos

## Install
1. Open `chrome://extensions` and enable **Developer mode**
2. Click **Load unpacked** and select the `chrome-shortcuts` folder
