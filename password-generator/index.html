Features

Everything you need, nothing you don’t

A focused toolkit for creating credentials you can trust, wrapped in a clean Material Design interface.

Three generators

Random passwords, BIP‑39 passphrases and numeric PINs — one tap apart.

Secure by design

Powered by the Web Crypto API with rejection sampling, so every character is unbiased and unpredictable.

Private & offline

No network requests, no analytics, no accounts. Everything happens on your device.

Live strength meter

Entropy-based scoring and an estimated crack time update instantly as you tweak each option.

Privacy & security

Private by default

Your passwords are yours alone. The extension is deliberately small, auditable and quiet.

  • Only the storage permission — no access to websites or tabs.
  • History lives in session storage and disappears when the browser closes.
  • Zero network requests, zero telemetry — and open source, so you can audit every line.
Randomness
crypto.getRandomValues() with rejection sampling — never Math.random().
Passphrases
BIP‑39 wordlist · 2,048 words · 11 bits per word.
Strength
Entropy from the real character pool, with the crack-time estimated at 10 billion guesses per second.
Footprint
Manifest V3 · vanilla JavaScript · no dependencies.

Install

Up and running in a minute

Works on Chrome, Edge, Brave, Opera and other Chromium browsers.

1

Get the source

Download or clone the project folder that contains manifest.json.

2

Open extensions

Go to chrome://extensions and turn on Developer mode.

3

Load unpacked

Click Load unpacked and select the project folder.

4

Pin it

Pin Password Generator to the toolbar for one-click access.

Tip: Edge uses edge://extensions and Brave uses brave://extensions.
